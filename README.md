## Контрольные вопросы
1. Программа запрашивает эти данные у системы.
2. Роль посредника
3. ОС которая использует 64-битную архитектуру
4. Environment.ProcessorCount показывает число логических процессоров,
которые видит операционная система. Это число не обязательно совпадает с числом физических ядер.
5. Память процесса  — это отдельная часть от общего объема оперативной памяти.
6. Потому что разные компьютеры отличаются друг от друга компонентами и ОС.
